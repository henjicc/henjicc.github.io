# 安全与外部副作用

> 读取时机：实现输入校验、鉴权、特权接口、敏感数据处理，或执行有外部 / 破坏性副作用的操作时。

## 可信边界

- 按实际运行拓扑确定认证、权威校验、密钥、存储和系统能力的可信执行位置；客户端隐藏或校验不能替代可信侧检查。
- 校验放在真实输入或可信边界；同一可信边界内已由类型、解析或调用契约保证的条件，不逐层重复防御。不同权限、阶段或业务不变量的检查仍须保留，静态类型不能证明外部输入可信。解析失败不退化为宽松执行。
- 特权接口最小、具名且可校验，不暴露通用执行能力或原始 IPC；桌面应用通过这样的桥接访问宿主能力。权限失败安全拒绝并给出必要恢复信息。

## 数据与秘密

- 使用项目批准的环境变量、密钥链或秘密管理服务；不把真实秘密写入代码、fixture、日志、截图或提交。
- 测试优先隔离数据；真实账户、用户数据和付费能力按现有授权范围访问，不能默认所有本地命令都无生产影响。
- 只处理任务所需数据；遵守保留与脱敏约定。
- 用户的作品、影像、本机路径和个人信息不进仓库，按 [`private-content.md`](private-content.md) 处理。

## 操作授权

- 授权范围以 `AGENTS.md` 和 Git 规则为准。执行前先确认对象、环境、影响和恢复方式；已覆盖时直接执行，未覆盖时只暂停相关操作，继续可安全完成的准备工作。
- 高影响操作优先 dry-run、事务、备份或可回滚方案，执行后核对权威结果。
